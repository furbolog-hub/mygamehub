# Отложенные задачи проекта

## PWA для общего игрового портала

Статус: отложено по решению владельца проекта 20 августа 2026 года.

Когда вернёмся к задаче:

1. Добавить в тестовую версию общий `manifest.webmanifest` для игрового портала.
2. Добавить в HTML ссылку на манифест и безопасные PWA-теги для iOS и Android.
3. Сначала не подключать Service Worker, чтобы исключить влияние кэширования на браузерную версию игр.
4. Позже подготовить отдельную иконку приложения и добавить её размеры в манифест.
5. Отдельным этапом спроектировать и протестировать Service Worker; не кэшировать API сессий и предусмотреть обновление игровых файлов без показа устаревшей версии.
6. Проверить обычный браузерный режим и установленный режим в Chromium и WebKit/Safari на телефоне, планшете и компьютере.
7. После проверки тестовой версии переносить изменения в `public-release` только по отдельной явной команде.

Важно: установленное PWA на iOS может иметь отдельное хранилище относительно Safari. Перед публичным выпуском нужно отдельно проверить, как это взаимодействует с идентификатором установки и суточным лимитом игровых сессий.
