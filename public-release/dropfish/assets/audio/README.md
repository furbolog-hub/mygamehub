# Структура звуков

- `ui/` — интерфейс, справка и достижения.
- `fishing/` — заброс и обычные события рыбалки.
- `effects/` — бонусы и дебафы.
- `artifacts/` — получение артефактов по категориям.
- `characters/` — персонажи.
- `weather/` — смена погоды и погодный фон.
- `rifts/opening/` — открытие разломов.
- `rifts/ambient/` — фоновый звук разломов.
- `abyssal/events/` — появление и воздействие абиссальной формы.
- `islands/opening/` — открытие островов.
- `islands/music/` — фоновая музыка островов.
- `islands/dangers/` — опасные события островов.
- `ships/` — торговое судно и «Рециклон».
- `dungeons/<dungeon>/` — события подземелья и фоновая музыка боя.

Новые файлы подключаются через единый реестр `SOUND_PATHS` в `script.js`.
