# Колыбель Левиафана — изображения

Тестовый комплект второго подземелья. Сцена использует общий фиксированный холст 720×1280 и наследует изображения оружия, сундуков, сфер и союзников из `../eternal-darkness-vault/`.

- `entrance.webp` — экран входа.
- `dungeon-interior.webp` — фон трёх уровней.
- `piranhas-leviathan-cradle.webp` — Пираньи Колыбели Левиафана.
- `boss-leviaxar.webp` — Левиаксар.
- `loot-leviaxar-blood.webp` — Кровь Левиаксара.
- `loot-carapace-scale.webp` — Панцирная чешуя.
- `loot-corrupted-heart-pearl.webp` — Жемчужина осквернённого сердца.
- `effect-leviaxar-wrath.webp` — Гнев Левиаксара.
