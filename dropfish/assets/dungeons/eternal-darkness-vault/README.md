# Хранилище вечной тьмы — изображения

Все файлы используются только тестовой версией DropFish. Формат — WebP с прозрачностью для иконок.

- `entrance.webp` — вертикальная заставка входа.
- `dungeon-interior.webp` — вертикальный фон трёх уровней.
- `chest.webp` — закрытый сундук.
- `ally-orb.webp` — сфера союзника.
- `piranhas-eternal-darkness.webp` — стая пираний вечной тьмы.
- `boss-ballistier.webp` — Балистьер без фона.
- `weapon-dagger.webp`, `weapon-sword.webp`, `weapon-hammer.webp`, `weapon-shield.webp` — оружие.
- `ally-electric-eel.webp`, `ally-stonefish.webp`, `ally-goblin-shark.webp`, `ally-yeti-crab.webp` — союзники.
- `loot-ballistier-eye.webp`, `loot-burning-core.webp`, `loot-abyss-core.webp` — трофеи.
- `effect-ballistier-wrath.webp` — эффект «Гнев Балистьера».

Рекомендуемые размеры: фоны 720×1280 или больше; босс 768×768; остальные иконки 256×256 или 512×512.
