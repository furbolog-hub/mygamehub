# DropFish — торговое судно и «Рециклон»

Правила механики:
- После последнего заброса в любую погоду, кроме Шторма, торговое судно прибывает с вероятностью 50%.
- При прямой поимке рыбы удочкой с вероятностью 40% дополнительно находится специальный предмет.
- Судно принимает 3 случайных вида предметов из 6.
- Каждый предмет обменивается на тяжеловеса (90%) или рыбу-гиганта (10%).
- Если подходящих вариантов обмена нет, судно автоматически завершает визит.
- Если обмен доступен, в записи прибытия в хронологии появляется кнопка `Торговля`. Окно открывается только по нажатию игрока.
- Игрок сам выбирает отдельные предметы, артефакты и островную добычу либо запускает обмен всего подходящего сразу.
- «Рециклон» также требует подтверждения переработки хлама через кнопку торговли.
- Итоги сессии, достижения и дата завершения рассчитываются после ухода судна.
- Рыба от судна входит в итоговый вес и получает финальные усиления, но не считается прямым уловом и не атакуется Касаткой.
- При завершении сессии полноэкранное уведомление о достижениях не показывается. Открытые достижения доступны через соответствующий значок и в сохранённых результатах.

Основные параметры находятся в `BALANCE.tradeShip` в `script.js`.
