# Q: Почему Обсидиановый ключ не дал выбор после смены погоды?

## Answer

Ключ ставит obsidianArmed и перехватывает только changeWeatherRandomly(), вызываемый с базовым случайным шансом после заброса. Тогда он предлагает две погоды. Прямые смены через applyRandomWeather(), включая Первобытный хаос, и Компас проходят мимо ключа, поэтому текущая подсказка двусмысленна.
