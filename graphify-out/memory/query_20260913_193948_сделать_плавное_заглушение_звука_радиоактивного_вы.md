# Q: Сделать плавное заглушение звука радиоактивного выброса после последнего доступного заброса

## Answer

Expanded from original query via graph vocab: radioactive, audio, sound, cast, finish, finished, fade, stop, ambient, session. startRadioactiveOutbreak теперь сохраняет отдельный экземпляр звука через startRadioactiveSound; endRadioactiveOutbreak запускает 800-мс затухание через stopRadioactiveSound, после чего аудио ставится на паузу и перематывается.
