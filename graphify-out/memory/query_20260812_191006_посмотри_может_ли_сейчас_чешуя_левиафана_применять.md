# Q: Посмотри может ли сейчас чешуя левиафана применять свое свойство к островным рыбам и рыбам разломов?

## Answer

Expanded from original query via graph vocab: [leviathan, fish, island, islands, rift, relic]. Проверка актуального тестового dropfish/script.js: к рыбам Разлома Чешуя Левиафана применяется, потому что commitRiftFish вызывает makeFish, а makeFish без ограничения по source добавляет возрастающий бонус +5 кг за шаг. К островным рыбам не применяется: commitIslandLoot создает исполинов, мурен, гранитных сомов, эхоносных скатов и стандартную рыбу припасов напрямую и не вызывает блок Чешуи в makeFish.
