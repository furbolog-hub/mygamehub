# Q: Как собрать и безопасно опубликовать механику радиоактивного выброса DropFish в тестовый и публичный репозитории?

## Answer

Тестовый релиз публикуется из изолированного индекса origin/main с исходником, CSS, HTML, ассетами, тестами и сборщиком. Публичный релиз собирается scripts/build-public-games.ps1 для dropfish: debug-блоки удаляются, unlimitedSessions переключается в false, bundle минифицируется и обфусцируется, затем отдельно сохраняется публичный HTML с data-game и session guard. Перед push проверяются синтаксис, obfuscation signature, отсутствие debug, Worker deployment, D1 и secret. Публичный коммит создается из отдельного индекса public-portal/main с GIT_WORK_TREE=public-release и точным allow-list файлов.
