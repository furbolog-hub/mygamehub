# Q: Почему иконки артефактов обрезались во вкладках справочника?

## Answer

artifactIconMarkup создаёт artifact-entity-icon is-guide-icon, но базовый CSS помещал изображение 64x64 в контейнер 34x34 с overflow:hidden. Для guide-epic, guide-legendary и guide-mythic добавлено отдельное вписывание изображения 32x32 и overflow:visible.
