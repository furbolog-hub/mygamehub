# Q: Что за сбой панцирных чешуй - поясни что там не так?

## Answer

Expanded from original query via vocab: [activatable, clean, finish, fish, reward, rewards, weight, weighted, weights]. Это ложное падение недетерминированного теста, а не подтверждённый дефект Панцирной чешуи. Тест создаёт четыре рыбы initialWeight=10 и ожидает сумму 40, но fresh() оставляет случайную погоду initialState(). В прогоне выпал Золотой час, makeFish добавил каждой рыбе +1 кг, поэтому чистый вес стал 44. Обе чешуи корректно записали один pre-effect clean weight 44 и максимальный вес рыб стал 44. Исправлять следует тест: зафиксировать нейтральную погоду либо вычислять ожидаемый чистый вес перед finishGame.
