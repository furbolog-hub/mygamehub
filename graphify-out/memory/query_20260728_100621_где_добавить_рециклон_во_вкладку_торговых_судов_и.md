# Q: Где добавить Рециклон во вкладку торговых судов и убрать emoji-заглушки справочника?

## Answer

Данные вкладок находятся в GUIDE, а заголовки рендерятся openGuide(). Рециклон перенесён из Островов в новую вкладку Торговые суда; текстовые emoji удалены, динамические заголовки очищаются, а для бонусов, дебафов, артефактов, Разломов и абиссальных форм используются существующие изображения-иконки.
