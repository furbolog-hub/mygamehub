# Q: Исправить: Метаморф иногда показывает одинаковый вес до и после мутации; экспедиционный предмет на последнем забросе нельзя изучить до завершения сессии

## Answer

Expanded from original query via vocab: [metamorph, relationships, expedition, artifact, item, cast, session, finish, finished, complete]. В dropfish/script.js changeAbyssFishWeight получил режим ensureChanged, который после округления гарантирует отличие минимум на 0,1 кг; Metamorph включает этот режим. maybeFinalizeSession теперь ждёт active экспедиционные предметы, а неудачная расшифровка на последнем забросе повторно запускает финализацию. Целевые тесты и синтаксис прошли; полный npm test остановился на несвязанном существующем тесте Carapace Scales.
