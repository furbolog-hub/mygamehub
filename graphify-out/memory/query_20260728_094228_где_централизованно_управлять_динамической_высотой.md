# Q: Где централизованно управлять динамической высотой основных и дочерних строк хронологии?

## Answer

Основные строки формируются в renderHistory(), дочерние — в renderEmbeddedFishList(). Единый rowHasExtendedContent позволяет переключать классы is-compact-row/has-extended-content при каждом рендере; дочерние строки автоматически определяют дополнительные блоки CSS-селектором :has(> :not(.embedded-fish-main)).
