# Q: Где настроить фон строк добычи, рыб и реликвий Разлома в хронологии?

## Answer

Общая строка задаётся .history-item.type-rift, дочерние рыбы — .history-item.type-rift .embedded-fish-item, добыча — .rift-loot-result-item, а реликвии дополнительно выделяются .type-relic.
