# Q: Как реализован Обсидиановый ключ для всех автоматических смен погоды?

## Answer

changeWeatherRandomly(source) стал общей точкой обычной случайной погоды и Первобытного хаоса. Взведённый ключ предлагает две погоды, исключая текущую, сохраняется до выбора и только затем помечает конкретную реликвию использованной. Компас остаётся отдельным ручным выбором.
